## The decisions

### Timestamp backfill as a metadata-only, byte-preserving operation — *model-behavior-as-design*

Rather than regenerating or touching articles to add missing popover bindings, we built a deterministic replay script that adds only the three missing October merge-clock popovers while leaving every article byte, prior binding, and provenance record intact. The replay script re-reads the original raw source events from the indexed event log — the same inputs available at original generation time, now fully indexed — and recomputes bindings deterministically from those inputs. Running it again produces identical output. The script lives in daily-logger under scripts/backfill/. This is the correct tradeoff because article text carries its own provenance chain: modifying it to fix metadata would corrupt the editorial history the review pipeline depends on.

### Diagnostic prefix boundary as a first-class test fixture constraint — *tooling-for-iteration*

The eval fixture was silently passing four healthy ADR entries that were pushing the corruption marker beyond the 1,500-character diagnostic prefix, causing the assertions to miss their target evidence. The alternative — raise the character limit in tests — was rejected because the 1,500-character boundary is enforced at runtime by the production eval harness, not just in test configuration. Expanding it in tests would mean asserting against evidence the production system can never see, creating a passing test suite that doesn't reflect production behavior. Fixing this by reducing the fixture keeps the test honest. The remaining gap: fixture size is not currently checked at commit time, so a future prompt change could re-introduce the same silent failure.

Tags: `ci-cd`, `hardening`

### Agent orientation as the first line of defence against timestamp coverage errors — *assistant-centric*

Core PR #539 teaches the timestamp evidence lifecycle in the daily-logger orientation before agents encounter it in practice. The failure mode being prevented is an agent mistaking a merged UI element or empty reference array for complete coverage of the latest article — a silent correctness gap that produces no error, just wrong metadata. Documentation at the orientation layer means the constraint is present in every future agent's context window from the first prompt, not only discoverable by reading the code. This complements but does not replace mechanical enforcement.

Tags: `provenance`, `model-behavior-as-design`

### Appended feedback without losing original note — PR correspondence model — *security-as-emergent-ux*

The editorial discussion model now permits the owner to append full attributed feedback versions to an existing acceptance PR rather than requiring a new PR per feedback round. This avoids exploding PR count while preserving complete feedback lineage. The tradeoff is that the PR body grows with each appended round, but that is preferable to losing the correspondence thread across separate PRs or silently overwriting earlier feedback.
