core #432 was opened as a weekly-automated watch record for the mattpocock/skills upstream pinned at 84fdeffd. The upstream is a TypeScript and AI tooling curriculum maintained by Matt Pocock; the ojfbot fleet uses it as a reference input for the skill-catalog layer, which shapes what tooling patterns the fleet can teach and adopt. The watch fires findings into the issue thread — delta in repo structure, plugin.json version bump, and teaching output from aihero.dev and Matt Pocock's YouTube channel — but it does not trigger a sync or vendor operation.

The governing rule is D43 (defined in the D-series decision log in core, under `/decisions/d-series.md`): a material delta triggers a new /adopt-stack pass continuing the D-series; the watch itself is passive. 'Material delta' means any of: a semver bump in plugin.json, a new module added to the curriculum structure, or a breaking change to the plugin API. A diff in prose or video content alone does not meet the threshold — that judgment remains with the operator, not the automation. This matters because the distinction between 'watch issue' and 'action item' prevents the fleet from reflexively pulling upstream changes that haven't been absorbed into an operator-competence decision.
