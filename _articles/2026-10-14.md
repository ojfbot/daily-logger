## The decisions

### Literal feedback preservation as a hard invariant, not a best-effort copy — *model-behavior-as-design*

The editorial acceptance pipeline's normalisation step was silently eating delimiter characters and Unicode sequences in multi-line editorial notes, changing their meaning before they reached the revision prompt. PR #347 hardened the path to treat root and section notes as opaque byte strings end-to-end. Any transformation — trimming, normalisation, delimiter removal — is now a correctness failure. The alternative was to continue processing feedback as display text; the failure mode was an untrustworthy editorial loop whose corruption was invisible at submission time and only visible in the published output.

### Evidence budgeting: a measured character ceiling rather than source-count limits — *tooling-for-iteration*

The previous per-source count admitted a single very long PR body at full length while starving shorter sources, producing summaries that over-represented one contributor's work. PR #348 replaced this with a 24,000-character ceiling distributed across all merged PR evidence. The number was set empirically against the actual corpus; the trigger for revisiting it is a measurable shift in PR body length distribution. The article explicitly does not claim this is a token budget or an accuracy guarantee — the model stage's context window behaviour is not observable from the pipeline side. What this doesn't cover: it does not prevent a single source from being semantically dominant if its content is high-signal; relevance ranking was considered and deferred because it introduces model-stage dependency at the evidence-selection layer.

### Digest binding as the anti-substitution gate in the publication checker — *security-as-emergent-ux*

Without this gate, a delivery receipt could reference the correct preparation record but describe a different article body — passing structural validation while misrepresenting content identity. Core PR #527 quarantines any receipt whose `publication_intent` names a `body_digest` different from the producer's recorded projection. On failure: the receipt is written to a quarantine directory and the delivery stage halts; recovery requires re-running the producer with the correct artifact and regenerating the receipt. The contract is Proposed — the check runs and enforces in the checker, but does not yet gate live publication. Promotion criteria are in ADR-0108 and require a passing end-to-end conformance run against a live delivery. Synthetic conformance does not qualify.

### Orphan vs. staleness separation in the vault scanner — *tooling-for-iteration*
