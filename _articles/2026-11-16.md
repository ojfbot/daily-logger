## The decisions

### Repo-sync loop promoted from ad-hoc hook to versioned core script — *security-as-emergent-ux*

The Yojimbo SessionStart hook (~/.claude/hooks/core-main-ff.sh) was an unversioned, single-host script with no Yuri equivalent and no audit trail. Promoting the logic to scripts/repo-sync.mjs in core means both Macs share one reviewed implementation, the installation step is an explicit operator decision per host, and the sync history lands in ~/.claude/repo-sync/runs.jsonl rather than disappearing on session end. The loop is committed but not yet installed on either Mac; that is the design. Installing it changes what runs at the OS level on a specific machine — wiring a launchd or cron job — and requiring explicit operator confirmation per host means no Mac picks up new scheduled behaviour without the owner's knowledge. This is the same pattern used throughout the fleet for any persistent background process. The tradeoff is that the loop confers no benefit until installed, but that owner gate is the point, not a limitation. A tracking item for the actual per-Mac install steps is not in this window; that is an acknowledged open gate.

### Fast-forward safety split: update-ref vs. merge --ff-only by checkout state — *security-as-emergent-ux*

A fast-forward that overwrites an active worktree's HEAD without checking for uncommitted edits destroys work silently. The loop distinguishes two cases precisely. Main not checked out: git update-ref is called with the current local SHA as the expected old-value and the fetched remote SHA as the new-value; the write is atomic and fails if any concurrent process has moved the ref since the ancestry check, surfacing as a report entry. Main checked out: git merge --ff-only is used, which git itself refuses if the working tree is dirty. Any divergence, local-ahead state, or in-progress rebase, merge, cherry-pick, or revert causes the loop to report and do nothing. This is conservative by design — the right failure mode is a noisy report, not a silent forced reset.
