## The decisions

### Deposit emits evidence; reconciler flags absence — not silent writes — *model-behavior-as-design*

The teach corpus deposit (deposit.mjs) writes a lesson record and emits a sidecar JSON evidence file to teach/evidence/{session-id}.json on every completed session. A second script, reconcile-teach-deposits.mjs, scans that directory and flags any session that deposited no evidence file. The failure mode of the alternative (naive append-only write with no artifact) is the one that motivated this: a session that cold-starts placement — skipping every prior record — would still write a clean append, and nothing would signal the gap. By making the evidence a discrete file rather than a field, absence is structurally detectable rather than inferrable. This directly addresses TD-006. ADR teach-corpus-deposit-architecture R2 ratifies the preservation ruling: decayed evidence is kept as-is, not edited, so the reconciler's absence signal remains meaningful over time.

### Zero-JS quiz: radio inputs and :checked selectors, no script execution — *tooling-for-iteration*

Lesson quizzes use HTML radio inputs and CSS :checked selectors exclusively — no JavaScript. The fix (6d13e38) corrected a regression where the quiz was written with JS event listeners that never fired because the side panel renders lessons as static snapshots without a script runtime. The zero-JS constraint is not a limitation: it is the architecture that makes interactivity portable to any rendering surface, including Obsidian attachments, without an origin or script runtime. The failure mode of the JavaScript path is permanent — the side panel is a static renderer by design and that is unlikely to change. Any future quiz feature that reaches for JS should be rejected at review with this ADR as the citation.
