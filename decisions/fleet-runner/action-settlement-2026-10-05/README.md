The unfiltered 186-action rebuild also establishes that each of the 72 original done records matches exactly one source under explicit-ID or legacy matching (8 explicit-ID matches; all 72 legacy matches). Original IDs, descriptions, repositories, commands and source dates are unchanged in both ledgers. Repository resolution is evidence metadata only: for example, GitHub resolves `gcgcca` to `capture-agent`; historical source names are preserved.

This PR only supplies qualified ledger records and the resulting action projection; no lifecycle code, workflow or new identity is introduced.
